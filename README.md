# 🔀 Bhavya's AI Flow

Visual node-based canvas for building autonomous multi-step AI workflows, conditional branches, and automated task pipelines.

---

## 📂 File & Folder Structure — Direct Edit Guide

| File / Folder | What It Does | When to Edit |
| :--- | :--- | :--- |
| `index.html` | SVG node editor canvas & tool palette | Edit node types (Trigger, LLM Prompt, API Call, Condition) |
| `style.css` | Flowchart connector lines & node styling | Adjust line curving, node glow, and connector port styles |
| `app.js` | Graph evaluation engine & state propagation | Edit node execution order, data serialization, and graph export |
